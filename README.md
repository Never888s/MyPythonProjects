# 🤖 Игра «Угадай число» с эффектом печатной машинки

Мой самый первый проект на Python! Это консольная игра, в которой компьютер загадывает случайное число, а игрок должен угадать его за ограниченное количество жизней.

## 🚀 Основные фичи проекта:
* **Эффект печатной машинки** — текст выводится плавно по одной букве, как на старой клавиатуре.
* **Система жизней** — у игрока есть всего 3 попытки, после чего игра завершается.
* **Обработка ошибок** — если случайно ввести буквы вместо числа, игра не сломается, а вежливо попросит повторить ввод.
* **Система перезапуска** — в конце раунда можно начать заново без перезапуска кода.

## 💻 Как запустить:
1. Установите Python.
2. Скачайте файл `my_first_game.py`.
3. Запустите его в терминале или через VS Code командой:
   ```bash
   python my_first_game.py
   ```
